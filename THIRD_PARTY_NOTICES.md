# Third-party dependencies / 第三方依赖

No third-party source code is bundled. Runtime dependencies are installed separately:

- **python-dateutil** — recurrence rule processing; dual Apache-2.0 / BSD-3-Clause licensing. See the installed distribution's LICENSE files and https://github.com/dateutil/dateutil.
- **tzdata** — IANA timezone data; Apache-2.0 for the Python package and public-domain timezone data. See the installed distribution's licenses and https://github.com/python/tzdata.

本项目不打包第三方源码。依赖单独安装，具体条款以所安装发行包的许可证为准。
